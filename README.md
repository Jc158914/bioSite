# bioSite — Juan Emigdio Cardenas

## Project Overview
This bioSite project was created for CSD 340 Web Development with HTML and CSS. It presents the life, family, interests, and personal goals of Juan Emigdio Cardenas through three connected web pages, photographs, and captions.

## Pages
- `index.html` — Landing page introducing Juan, his family, soccer, running, and marathon goals.
- `about.html` — Background, family, life experiences, and biographical details.
- `hobbies.html` — Running, soccer officiating, and family-related interests.

## Project Structure
- `index.html`, `about.html`, `hobbies.html` — The website's three pages.
- `site.css` — Shared stylesheet controlling typography, colors, navigation, page layouts, image presentation, and responsive design across all three pages.
- `images/` — Photographs used throughout the website.
- `README.md` — Project documentation.

## Responsive Design
The shared stylesheet uses flexible images and media queries to adapt multi-column layouts, story cards, and navigation for tablet and phone screens.

## Viewing the Website
Visit the GitHub Pages deployment at https://jc158914.github.io/bioSite/ or open `index.html` in a web browser. Use the navigation links to visit the About and Hobbies pages.
